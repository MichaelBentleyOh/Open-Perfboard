# E2E 테스트 목록

앱(Electron)을 실제로 띄워 사용자처럼 조작하는 테스트다. `npm run test:e2e`(빌드 후 실행), 포장된 앱으로는 `npm run test:packaged`.
테스트마다 빈 사용자 데이터 폴더로 앱을 띄우므로 내 부품함을 건드리지 않는다. 공통 도구는 [launch.ts](launch.ts).

아래 "지키는 것"은 그 테스트가 실패하면 깨졌다는 뜻이 되는 동작이다. **테스트를 더하거나 지우면 이 표도 고친다.**

## 겹치지 않게 하는 원칙

- 계산·변환 규칙(경로 찾기, BOM 금액, 파일 검증 등)은 `tests/core`의 단위 테스트가 맡는다. E2E는 **화면 조작이 그 기능을 실제로 부르는지**를 본다.
- 같은 동작을 두 E2E가 확인하지 않는다. 새 단계는 가장 가까운 기존 테스트에 덧붙이고, 앱을 한 번 더 띄우는 새 테스트는 꼭 필요할 때만 만든다.
- 정리 기록: `mode.spec`(모드 키·부품 피하기·배선 정리 → help·avoid·tidy와 겹침), `smoke.spec`(앱이 뜨는지 → 모든 테스트가 확인)은 지웠다.
  `start.spec`의 최근 목록 순서·목록 지우기는 `recent.spec`으로 몰았다.

## 앱 기본·보안

| 파일 | 지키는 것 |
|---|---|
| navigation | 앱 창이 다른 페이지로 넘어가지 않는다. 외부 HTML이 `window.api`(파일 읽기·쓰기)를 얻지 못하게 하는 보안 테스트 |
| panels | 부품함·선택 항목 창을 접으면 캔버스가 넓어지고, 다시 켜도 접힌 상태를 기억한다 |
| report-layout | 좁은 창에서도 BOM·결선표 표가 카드 밖으로 넘치지 않는다 (가로 스크롤, 영어, 작업실 포함) |
| help | 창 제목, ?·F1·버튼으로 단축키 도움말 열기, 목록이 실제 단축키와 같음, 열려 있는 동안 캔버스 키 무시, W/V 모드 키와 안내, 영어 |
| i18n | 한국어↔영어 전환이 화면·알림·BOM CSV 머리글·저장 대화상자 제목까지 적용되고, 다시 켜도 유지된다 |

## 시작·파일

| 파일 | 지키는 것 |
|---|---|
| start | 홈 화면 두 버튼 → 배선도 → 홈 → 최근 배선도로 이어서 작업 → 부품 작업실, 영어. `.opb`로 실행하면 홈을 건너뛴다. 홈 목록의 ✕는 파일을 지우지 않는다 |
| file | 저장(`.opb` 자동), 저장 안 됨 `*` 표시, 실행 취소 후 깨끗한 상태로 돌아옴, 새로 만들기·열기, BOM·결선표 CSV, PNG, 바뀐 채로 닫으면 저장할지 묻기 |
| recent (1) | 파일 메뉴 최근 파일: 최근 것부터, 항목마다 ✕, 없어진 파일은 흐리게 → 누르면 빼기, 목록 지우기 |
| recent (2) | 파일 연결: `.opb`로 실행하면 그 파일, 실행 중에 다른 파일을 열면 같은 창에서 |
| recovery (1) | 자동 저장: 강제 종료 → 다시 실행하면 복구 → 원래 파일에 저장. 정상 종료면 묻지 않는다 |
| recovery (2) | 저장 안 한 새 배선도를 복구하다가 버리면 빈 새 배선도 |
| sheets | 여러 배선도 탭: 탭마다 따로 실행 취소, 이름 바꾸기, BOM 범위·합치기·배선도별 단가, `.zip` 저장·열기, 삭제 |

## 배선도 편집

| 파일 | 지키는 것 |
|---|---|
| canvas | 핵심 흐름: 배치(U1, U2) → 전선 연결 → 색·라벨 → 중복 연결 거부 → 회전·삭제 → 실행 취소·다시 실행 |
| avoid | 전선이 부품을 가로지르지 않는다: 잇는 순간 돌아가고, 부품을 전선 위로 옮기면 비킨다. 실행 취소 한 번에 함께 |
| tidy | 잘게 계단진 전선은 연결할 때 정리, 큰 우회로는 남김, 배선 정리 버튼, 실행 취소 순서 |
| bent-wire | 꺾임점: 그리는 중 빈 곳 클릭·Backspace·Esc, 직각↔직선, 손잡이 끌기·더블클릭으로 추가·삭제, 함께 이동 |
| junction (1) | 전선 중간을 끌어 핀 위에 놓으면 바로 분기 연결, 한 번 취소하면 원래 전선 하나로 |
| junction (2) | 교차 점프, 접속점(SP1) 분기, 결선표 표시, 접속점 이동, 가지 전선을 지우면 다시 합쳐짐 |
| multiselect | 사각형으로 선택, 함께 이동, Ctrl+클릭, 화면 이동(휠 버튼·Space), 삭제하면 BOM·결선표가 같이 바뀜 |
| copy-paste | 마우스 위치에 붙여넣기, 연속 붙여넣기는 비켜 놓기, 잘라내기, 입력칸에서는 글자 복사, 다른 배선도에 붙여넣기 |
| align | 부품 줄 맞추기(위 맞추기·같은 간격), 실행 취소 1회씩 |
| resize | 모서리 손잡이·]·[ 키·버튼으로 부품 배율과 글 상자 크기, 실행 취소 |
| flip-pdf | 좌우(F)·상하(Shift+F) 반전, PDF 내보내기 쪽 수, 작성자·비고 저장 |
| zoom | 배율 입력칸, Ctrl+0·=·- 단축키, Home = 전체 보기, 앱 화면 전체는 확대 안 됨, BOM 탭에서는 배율 키 무시 |
| notes-search | 글 상자 만들기·고치기·옮기기, 격자 맞춤, 다른 배선도에 있는 것도 찾아가기, 글을 다 지우면 삭제 |
| color-spectrum | 전선 사용자 색: HEX·RGB 입력, 스펙트럼 끌기, 적용할 때마다 실행 취소 1회 |
| large | 큰 배선도: 화면 밖은 그리지 않지만 PNG에는 전부, 결선표는 보이는 행만, 배선 정리 진행 창·취소 |

## 부품·라이브러리

| 파일 | 지키는 것 |
|---|---|
| library | 부품 만들기 → 핀 찍기(자동 번호) → 번호 수정 → 배경 지우기(투명 PNG) → 저장 → 다시 켜도 남음 → 삭제하면 파일도 사라짐 |
| pin-guides | 보조선 긋기(수평 맞춤), 핀 N개 고르게, 선 근처에 찍으면 붙기, 간격 맞추기, 붙이기 끄기, 보조선 통째로 옮기기 |
| drawing | 그림판에서 상자·원·선·글, 색, 실행 취소, 사진으로 구워지고 원본도 저장, 다시 열어 고치기. 부속 부품도 |
| symbol (1) | 회로도 기호: 핀 끌기(격자), 전기 종류, 핀을 지우면 기호에서도, 새 핀은 "놓지 않은 핀"에 |
| symbol (2) | 기본 기호 모양 고르기(NPN 핀 자리를 이름으로 맞춤), 삼각형·닫힌 선 도구 |
| studio | 부품 작업실: 부품·부속 부품 만들기·복제, 새 부품함 파일 저장·열기, 내 부품함에 넣기 |
| library-import | `.opblib`·`.opb`에서 가져오기, 충돌 처리(사본·건너뛰기·덮어쓰기), 망가진 부품 거부, 내보내기 |
| embed-library | 배선도에 라이브러리 전체를 넣어 저장 → 빈 PC에서 열면 가져오기, 두 번째에는 묻지 않음 |
| attachments | PDF·그림 첨부(가짜 PDF 거부), 썸네일, 별도 창으로 열기, `.opblib`·`.opb`로 다른 PC와 공유 |
| purchase | 구매 링크를 BOM에서 열기, 형식 검사, 라이브러리에서 고친 값을 배선도 사본에 갱신, 실행 취소 |
| spec-panel | 속성 창에서 부품 스펙·전선 규격·메모 → BOM·결선표 반영, 라이브러리에도 저장, 실행 취소 |
| supplies | 부속 부품 등록, 전선 종류·수축 튜브, BOM에 넣을지 묻기와 제안 수량, 결선표, 내보내기, 짝 하우징 표시 |
